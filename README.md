# Aterra Landing Page — HTML + CSS + Vanilla JavaScript

Framework-free version migrated from the latest React/Vite source.

## Preview locally
Recommended: Visual Studio Code + Live Server.

1. Open this folder in VS Code.
2. Open `index.html`.
3. Right-click → **Open with Live Server**.

You can also open `index.html` directly in a browser, but Live Server is better for auto-refresh.

## Where to edit
- Main text/markup: `index.html`
- Main styles and mobile design: `css/style.css`
- Tablet/desktop overrides: `css/responsive.css`
- WhatsApp number, price, social/CTA links: `js/data.js`
- WhatsApp message format: `js/whatsapp.js`
- FAQ, video, quantity, animations, form behavior: `js/main.js`
- Images/fonts/video: `assets/`

## Primary design target
390px mobile.

## Important
External Instagram, TikTok, Shopee, Tokopedia, Order, and Promo destinations were not supplied in the source project, so they remain blank/fallback values in `js/data.js`. Do not invent them; fill them when official URLs are available.
